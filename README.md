## Overview

This repository contains my research paper, *"A Comprehensive Survey on Coreference Resolution,"* written at UC Berkeley. The paper traces the development of coreference resolution — a core task in Natural Language Processing (NLP) — from its origins in the late 1900s through to modern approaches, synthesizing decades of research into a single, accessible overview.

Coreference resolution is the task of determining when different expressions in a text refer to the same real-world entity (e.g., linking "she," "the scientist," and "Dr. Chen" to one person). It's a foundational problem for downstream NLP applications like summarization, question answering, and information extraction.
